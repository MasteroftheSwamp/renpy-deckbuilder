HELLO! HERES HOW TO INSTALL!

How to install:
step 1: Unzip and place RF file in the base directory of your game //~~ game/RF.
step 2: on start jump to label start_example to see what can be done with the Route Follower.

To download special examples go to the Route Follower Page and see the drop box link in the description!

ALSO MAKE SURE TO DELETE THE dev_route_editor.rpy, it will take up space and is not needed when game is finished!

That's it!
