~~ Look above, there are different variables inside the interact point. . .
 ● 'name': The name of the point
 ● 'point': The points coordinates
 ● 'label': The label the point will jump to when
 ● 'active': The label is active, so it can be interacted with, you can set this to False to have it deactivated until its changed

-- default follower = FollowerDisplayable(Follower(x=0, y=0, turn=True, free_movement=True, directional_mode="4", speed=200, route=None, img_id=None))

~~ If these values are all correct, (with exception to the route and img_id) for example

-- default follower = FollowerDisplayable(Follower(route=(DEFINED ROUTE HERE), img_id=(DEFINED IMAGE ID HERE)))


 ● x=0 // x position of the follower - Change this to place the follower at its starting position

 ● y=0 // y position of the follower - Change this to place the follower at its starting position

 ● turn=True // Toggles if turn is on or off - turn meaning the image will auto flip( from xzoom=1.0 to xzoom=-1.0), when False, this will allow you to use separated left and right images

 ● free_movement=True // Toggles if on click movement is on - If False follower cannot move unless set destination or set_button_destination function is called

 ● directional_mode="4" // The direction mode you would like your follower to use. There are 4 different modes to use that alter the image in a specific way.
 - - - - - "4" - only 4 image angles of movement - up, down, left, right
 - - - - - "8" - only 8 image angles of movement - up, down, up_left, up_right, down_left, down_right, left, right
 - - - - - "1" - only 1 image - does not alter the image in a direction, only uses one image
 - - - - - "free" - only free angles of movement - moves in the direction of the route line, best for top down type of images

 ● speed=200 // The speed at which the follower moves

 ● route=None // ** WARNING MUST BE CHANGED - Put the defined route line you created here!

 ● img_id=None // ** WARNING MUST BE CHANGED - Put the defined image library you created here!

## FOLLOWER MOVEMENT/FUNCTIONS ## -- 07
~~ Rest is very easy. There are 3 ways to move . . . when using it outside free_movement make sure to turn lock_plyr_cntrl True, to stop the point and click aspect.
Or player can accidentally cancel the path you want them to go down in a cutscene.

-- self.set_teleport(x,y,lines) // This teleports the player to the exact spot instantly.
-- $ follower.set_teleport (962,507,follower.route.lines) // example found in start_example.rpy

-- self.set_destination(x,y,lines) // This moves the player to the destination using coordinates(used in free movement, can be used in a function outside of free movement).
-- $ follower.set_destination(956, 608, BOARD_MAP2) // example found in special_start_example.rpy

-- self.set_button_destination(x,y,lines) // This moves the player to the destination using coordinates. BUT main difference being is this uses renpy buttons in order to move. Look below because its a little different.
////////////////////////////////////////////////////////////////////////////////
--  action [Function(follower.set_reach,"set_center"),SetVariable("lock_plyr_cntrl",True),Function(follower.set_button_destination, 962,507, follower.route.lines)] // example found in start_example.rpy

~~ This action above does this -> Makes follower move to destination, when reached jumps to label.
~~ Below I'll list out things you can use inside of these button actions . . .
 ● set_reach function // sets the label that the follower jumps to when reaching the destination.
 ● lock_plyr_cntrl variable change // if set to True, player will not be able to click to move around freely and cancel the path to the image buttons coordinates, if False the player can move freely and cancel the imagebuttons path.
 ● set_button_destination function // Moves follower to the destination. Only use this function inside renpy buttons
////////////////////////////////////////////////////////////////////////////////

~~ Last functions are like traffic light functions.
 ● $ follower.stop_follower() // This stops follower completely, removing the path and destination.
 ● $ follower.pause_follower() // This this pauses the followers route, it stores the path to be used later.
 ● $ follower.play_follower() // This resumes the followers path that it stored.
